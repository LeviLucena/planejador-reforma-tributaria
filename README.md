# Planejador da Reforma Tributária

Simulador local (CBS, IBS e IS) com os motores oficiais da Receita. Tudo escuta só em `127.0.0.1`.

- Usar: `scripts\iniciar.bat`; encerrar: `scripts\parar.bat`. Guia completo: [`docs/uso-local.md`](docs/uso-local.md).
- Desenvolvimento: `npm start`, `npm test`, `npm run build`, `npm run typecheck`; `npm run test:integracao` exige os motores no ar (`scripts\iniciar.bat`).
