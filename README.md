# Planejador da Reforma Tributária

Simulador local (CBS, IBS e Imposto Seletivo) que usa os motores oficiais da Receita Federal.
Tudo roda no seu computador, em `127.0.0.1`.

- Para usar: execute `scripts\iniciar.bat` e, para encerrar, `scripts\parar.bat`.
- Guia completo (instalação, premissas, selos, atualização dos motores, roteiro de verificação):
  [`docs/uso-local.md`](docs/uso-local.md).
- Comandos de desenvolvimento: `npm start`, `npm test`, `npm run test:integracao`, `npm run build`,
  `npm run typecheck`.
